# Plaudia — Règles strictes

Ce fichier est chargé automatiquement quand Hermes travaille dans ce projet.  
**NE JAMAIS contourner les règles ci-dessous.**

## ⚠️ OBLIGATOIRE : Skills à charger

Avant toute action sur Plaudia (cron, génération CR, RAG, modification, debug), tu DOIS charger CES deux skills :

1. `plaudia-recording-pipeline` — template CR, format A4, glossaire, pipeline
2. `plaudia-orchestrator` — architecture globale, crons, troubleshooting

Charge-les avec :
```
skill_view(name='plaudia-recording-pipeline')
skill_view(name='plaudia-orchestrator')
```

**Ne JAMAIS** générer de CR, modifier le pipeline, ou toucher au watchdog sans avoir chargé ces skills.

## 🚫 Interdictions

- **NE PAS** écrire de script Python manuel pour générer un CR — utiliser la skill + le template
- **NE PAS** inventer mon propre prompt — recopier celui de `references/cr-generation-prompt.md`
- **NE PAS** modifier le watchdog sans vérifier la section "Watchdog" dans la skill
- **NE PAS** toucher aux credentials (`.env`, `mcp-tokens/`, `google_token.json`)
- **NE PAS** créer/modifier un cron sans lui attacher la skill correspondante

## ✅ Checklist avant toute action

- [ ] Skill `plaudia-recording-pipeline` chargée
- [ ] Skill `plaudia-orchestrator` chargée
- [ ] Template CR vérifié dans `references/cr-generation-prompt.md`
- [ ] Format A4 respecté (page-break, avoid-break, keep-with-next, pas de justify)
- [ ] Titre recording au format `[Entreprise] — [Type] — [Sujet] — [JJ/MM/AAAA]`
- [ ] Pipeline cron a `skills: ["plaudia-recording-pipeline"]`

## Architecture

```
Watchdog (5min, no_agent) → INSERT recordings → Pipeline CR (12h, skill) → INSERT crs
```

Le watchdog est un script pur (0 LLM). Le pipeline est un agent LLM avec la skill.
